## Project Overview
RaceDay is a web-based event management system developed using C# and ASP.NET Core Web API. It allows organisers to manage race events and participants to enrol in races and view their results.

## User Roles

**Organizer**
- Create, update and delete race events.
- Manage event information and results where supported.

**Participant**
- View available events.
- Enrol in races.
- View race results.

## Technologies Used
- C#
- ASP.NET Core Web API
- .NET 8
- SQL Server
- GitHub Actions
- xUnit and Moq for unit testing

## How to Run the Project
1. Clone or download the repository.
2. Open `RaceDay.sln` in Visual Studio.
3. Configure the SQL Server connection string.
4. Restore NuGet packages.
5. Run the API project.

## Running Tests
Run the following command in the terminal:

dotnet test RaceDay.sln

## GitHub Actions
GitHub Actions automatically builds the solution and runs the unit tests when changes are pushed to the repository.
